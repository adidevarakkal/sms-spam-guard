# Data

`sms.tsv` is the **SMS Spam Collection v.1** (5,574 English SMS messages labelled `ham` or `spam`), by Tiago A. Almeida and José María Gómez Hidalgo, published in the UCI Machine Learning Repository under a CC BY 4.0 licence. This copy is the tab-separated version from github.com/justmarkham/pycon-2016-tutorial.

Almeida, T. A., & Gómez Hidalgo, J. M. (2011). SMS Spam Collection [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CC84
